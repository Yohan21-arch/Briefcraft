Connect local AI

For reliable local use, download the project and serve it at http://localhost:8080. Hosted browsers may block access to localhost.

  1. Install Ollama.
  2. Download the open-weight model:
    ollama pull qwen3:4b
  3. Quit any running Ollama app. In PowerShell, run:
    $env:OLLAMA_ORIGINS="http://localhost:8080"
$env:OLLAMA_NO_CLOUD="1"
ollama serve
  4. From the downloaded project folder:
    python -m http.server 8080 --directory dist
    Open http://localhost:8080.

Only the loopback address http://localhost:11434 is used. No keys needed. Initial model download needs internet; subsequent local inference can work offline. To connect from the hosted page, allow its exact origin in OLLAMA_ORIGINS and any browser local-network permission.
